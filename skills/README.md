# Repo-Local Codex Skills

These skills are stored in the repository so contributors can share the same
RustLearn product, frontend, backend, and testing workflows.

- `product-owner` - define user value, acceptance criteria, and done/not-done
  decisions.
- `product-manager` - sequence roadmap work, dependencies, risks, and commit
  slices.
- `backend-dev` - implement Rust/Actix/Diesel API contracts, services,
  repositories, migrations, workers, and Rust tests.
- `frontend-dev` - implement product-grade Next.js/React UI against real
  contracts.
- `manual-tester` - manually verify rendered frontend flows in desktop/mobile
  browsers.
- `automatic-tester` - add and run repeatable frontend, backend, Compose, and
  Kubernetes tests.

Use these with prompts such as `Use $backend-dev ...` or copy/install the skill
folders into a Codex skill root when a local Codex session should auto-discover
them.
